# CHC — Captra Handies Custom & Bulk Furniture Platform

A premium custom and bulk furniture platform demo built with Next.js and Tailwind CSS.

## Features
- Public landing page with premium brand styling and customer segment gateways
- Design Studio with configurable furniture types, dimensions, materials, finishes, and live estimate
- Customer dashboard with progress timeline and delivery scheduling
- Bulk procurement portal with RFQ generation and volume discount calculator
- Admin/workshop coordination panel with order assignment workflow
- Mock API and realistic in-memory data for users, workshops, catalog templates, and active orders

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes
This app uses mock backend state and is intended as a polished frontend demo for the CHC platform.
